1. Product Overview

1.1 Product Name

SwasthyaSaathi AI Health Assistant

1.2 Product Vision

An intelligent, conversational AI health assistant that provides personalized symptom assessment, natural remedy recommendations, and appropriate medical guidance through an intuitive chat interface, making quality healthcare accessible to all Indian users.

1.3 Product Mission

To democratize healthcare access by providing instant, accurate, and culturally-relevant medical guidance through AI-powered symptom analysis, prioritizing natural remedies while ensuring timely medical intervention when necessary.

1.4 Target Users

  • Primary: Indian patients (18-65 years) seeking initial health guidance
  • Secondary: Caregivers managing family health
  • Tertiary: Rural/semi-urban populations with limited healthcare access

2. Problem Statement

2.1 Current Challenges

  1. Limited Access: Many Indians lack immediate access to medical professionals
  2. Cost Barriers: Initial consultation fees deter early medical intervention
  3. Information Overload: Generic online symptom checkers provide overwhelming, often irrelevant information
  4. Cultural Gap: Western-focused health apps ignore traditional Indian remedies and practices
  5. Triage Inefficiency: Emergency cases often delayed due to lack of initial assessment

2.2 User Pain Points

  • "I don't know if my symptoms are serious enough to visit a doctor"
  • "I want natural home remedies before trying medications"
  • "Online symptom checkers ask too many irrelevant questions"
  • "I can't afford consultation fees for minor issues"
  • "I need quick guidance in emergency situations"

4. Core Features & Requirements

4.1 Feature: Conversational Symptom Assessment

4.1.1 User Stories

As a patient, I want to describe my symptoms in natural language so that I don't have to navigate complex medical forms.

As a patient, I want the AI to ask only relevant follow-up questions so that I can get quick results without frustration.

As a patient with severe symptoms, I want immediate emergency alerts so that I can seek urgent care without delay.

4.1.2 Functional Requirements

ID Requirement Priority Acceptance Criteria
FR-1.1 Single text input for symptom description P0 User can type symptoms in free text; no mode selection required
FR-1.2 AI asks 3-6 contextual follow-up questions P0 Question count: 3 min, 6 max; questions adapt to previous answers
FR-1.3 Real-time typing indicator during AI processing P1 "AI is thinking..." shown while waiting for response (<2s)
FR-1.4 Conversation progress tracking P1 Progress bar shows question count (e.g., "Question 2 of 6")
FR-1.5 Symptom-specific question trees P0 Headache → location, onset, severity; Fever → duration, pattern, chills
FR-1.6 Emergency keyword detection P0 "Chest pain", "can't breathe" → Immediate escalation within 1 question

4.2 Feature: Intelligent Triage & Classification

4.2.1 Severity Classification

✅ MILD (Green)

  • No red flags detected
  • Symptoms <3 days duration
  • Vitals within normal range
  • Self-care appropriate
  • Examples: Common cold, minor headache, mild muscle pain

⚠️ MODERATE (Yellow)

  • Some concerning symptoms but not life-threatening
  • Symptoms 3-7 days duration
  • Vitals slightly abnormal
  • Doctor consultation recommended within 24-48 hours
  • Examples: High fever >3 days, persistent cough, severe headache

🚨 EMERGENCY (Red)

  • Red flag symptoms present
  • Requires urgent medical attention
  • Doctor consultation within 2-6 hours
  • Examples: Chest pain, severe abdominal pain, high fever with confusion

4.2.2 Red Flag Detection Matrix

Symptom Category Red Flags Action
Chest Pain Radiation to arm/jaw, sweating, shortness of breath, family history CRITICAL → Alert emergency doctor
Headache "Worst headache ever", sudden onset, neck stiffness, fever, vision loss EMERGENCY → Urgent doctor needed
Abdominal Pain Severe pain >6 hours, blood in stool, rigid abdomen, pregnancy EMERGENCY → Hospital visit required
Fever >104°F (40°C), confusion, seizures, unresponsive, neck stiffness EMERGENCY → Immediate care
Breathing Can't complete sentences, blue lips/nails, wheezing, SpO2 <90% CRITICAL → Call ambulance
Neurological Facial drooping, arm weakness, speech difficulty (FAST stroke signs) CRITICAL → Call ambulance immediately

6. Technical Architecture

6.1 Technology Stack

Frontend (Mobile App)

  • Framework: React Native 0.72+ with Expo SDK 49+
  • Language: TypeScript 5.0+
  • State Management: React Context API + AsyncStorage
  • Navigation: React Navigation 6.x
  • UI Library: React Native Paper (Material Design)
  • HTTP Client: Axios with retry logic
  • Storage: Expo SecureStore for JWT tokens

Backend (API Server)

  • Framework: FastAPI 0.104+ (Python 3.11+)
  • Database: SQLite (development), PostgreSQL (production)
  • ORM: SQLAlchemy 2.0 with Alembic migrations
  • Authentication: JWT (PyJWT library)
  • AI Integration: Google Gemini Flash API
  • Monitoring: Sentry for error tracking

6.2 Database Schema

-- Users Table
CREATE TABLE users (
    id UUID PRIMARY KEY,
    phone VARCHAR(15) UNIQUE NOT NULL,
    name VARCHAR(100),
    email VARCHAR(100),
    password_hash VARCHAR(255),
    role ENUM('patient', 'doctor'),
    created_at TIMESTAMP DEFAULT NOW()
);

-- Consultations Table
CREATE TABLE consultations (
    id UUID PRIMARY KEY,
    user_id UUID REFERENCES users(id),
    session_id UUID UNIQUE,
    started_at TIMESTAMP DEFAULT NOW(),
    completed_at TIMESTAMP,
    triage_result JSON,
    conversation_state ENUM('chatting', 'complete')
);

-- Conversation Turns Table
CREATE TABLE conversation_turns (
    id UUID PRIMARY KEY,
    consultation_id UUID REFERENCES consultations(id),
    turn_number INT,
    role ENUM('user', 'assistant'),
    message TEXT,
    timestamp TIMESTAMP DEFAULT NOW()
);

7. User Flows

7.1 Normal Symptom Assessment Flow

START: User lands on Home Screen
  │
  ├─► Taps "AI Health Check" button
  │
  ├─► Chat Screen loads (auto-focused text input)
  │
  ├─► Types: "I have severe headache on left side" + Send
  │
  ├─► Backend: Detects symptom category = "headache"
  │
  ├─► AI responds: "How long have you had this headache?"
  │   (Question 1/6 shown)
  │
  ├─► User: "Since this morning, about 4 hours"
  │
  ├─► AI responds: "Is the pain constant or does it come and go?"
  │   (Question 2/6)
  │
  ├─► ... (3-6 total questions)
  │
  ├─► Backend: Completes triage
  │   Classification: MODERATE (migraine)
  │   Confidence: 82%
  │
  ├─► Auto-navigate to DoctorNeededDashboard
  │
  ├─► Shows:
  │   • Risk: Moderate - Doctor recommended within 24hrs
  │   • Natural Remedies: Rest in dark room, cold compress
  │   • OTC Meds: Ibuprofen 400mg with food
  │   • Connect to Doctor: [Shows 3 available doctors]
  │
  └─► User selects doctor or saves record

END

7.2 Emergency Case Flow (Fast-Track)

START: User describes chest pain
  │
  ├─► "I have severe chest pain spreading to my left arm"
  │
  ├─► Backend: Detects emergency keywords
  │
  ├─► AI: "This could be serious. Do you have shortness 
  │        of breath or sweating?" (Only 1 verification question)
  │
  ├─► User: "Yes, I'm sweating a lot"
  │
  ├─► Backend: Confirms CRITICAL emergency
  │
  ├─► IMMEDIATE auto-navigate to EmergencyDashboard (within 30 seconds)
  │
  ├─► Shows:
  │   • 🚨 EMERGENCY banner (flashing red)
  │   • "Call Ambulance: 108" button (largest)
  │   • "Alert Emergency Doctor" button (auto-clicked)
  │   • Do NOT: Drive yourself, eat/drink
  │   • While You Wait: Sit upright, loosen clothing
  │
  ├─► Emergency alert sent to all available doctors
  │
  └─► User waits with first-aid instructions visible

END (Emergency services engaged within 2 minutes)
